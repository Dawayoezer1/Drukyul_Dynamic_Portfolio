User guidelines: dynamic portfolio optimizer

A step-by-step guide to using the dashboard and reading its results.

Quick start in 8 steps
  1. Log in on this page, then press Open dashboard. It opens in a new tab at localhost:8501.
  2. Pick your dynamic portfolio. Choose stocks from the dropdown (company, ticker, exchange). Use Browse more stocks to refresh the US list or search and add global stocks.
  3. Set the dynamic strategy. Enter starting capital, base currency, rebalance frequency, lookback, risk aversion and the maximum allocation per stock.
  4. Open Backtest dates and risk settings and choose the comparison start and end dates, the risk-free rate and the minimum acceptable return.
  5. Enter trading costs from your own broker: commission, minimum charge, sell tax, spread and slippage, and FX conversion.
  6. Click Build dynamic portfolio & compare.
  7. Scroll down to read net returns, risk metrics, the dynamic versus static comparison, the Markowitz workings and the efficient frontier.
  8. Optional: use the live section to refresh prices and run a forward paper portfolio.
What each setting does
SettingWhat it does
Rebalance frequencyHow often weights are re-optimised, from every minute to yearly. More frequent means more trades and more cost.
LookbackThe number of completed return bars used to estimate returns and risk. It always ends before the trade, so no future data is used.
Risk aversionHigher means more cautious. The optimizer then favours lower-risk mixes over higher expected return.
Maximum allocation per stockA cap on every holding. It must be at least 100% divided by the number of stocks. With 7 stocks, use 15% or more.
Risk-free rateUsed in the Sharpe ratio.
Minimum acceptable returnUsed in the Sortino ratio and downside measures.
Trading costsApplied to both strategies, so the comparison is fair. Defaults are examples. Enter your real broker terms.
How the optimizer works
  • It maximises expected return minus a risk penalty, with weights that add up to 100%, no short selling, and your per-stock cap.
  • Expected returns come from the lookback window and are pulled towards the group average to reduce noise. Risk uses a shrunk covariance estimate.
  • A small turnover penalty discourages needless trading.
  • Static buys an equal-weight portfolio once and holds it. Dynamic re-optimises at each rebalance. Both start with the same capital, stocks, dates and costs.
  • The expected return, variance, volatility and Sharpe values on screen are estimates from past data. They are not forecasts.
Reading the results
  • Net return includes all trading costs. Cost drag shows how much fees reduced the result.
  • Sharpe, Sortino, Calmar and Omega measure return against risk. Drawdown shows the largest peak-to-trough fall.
  • VaR and expected shortfall are per observed interval, not annual forecasts.
  • Alpha, beta and tracking error use the static portfolio as the reference.
  • Choose a comparison priority: Sharpe (balance), net return (growth) or volatility (lower risk). The dashboard then reports which strategy the history favoured.
  • Histories under 180 calendar days or 60 observations are labelled as too short for an investment choice. Demo results never support one.
Data sources and limits
  • The default source is free Yahoo Finance. It may be delayed, rate-limited or unavailable. Wait and try again.
  • Daily data can cover long histories. Hourly, 15-minute and 5-minute data must fall within the last 60 days. One-minute data must fall within the last 7 days, including the lookback.
  • CSV upload is an offline option. Use columns date, ticker, close, adjusted, currency, one row per stock per timestamp, in a single currency.
  • The demo option uses synthetic prices and is labelled as such. Missing real data is never replaced with fake data.
Live paper portfolio
  • Click Refresh prices now to see the latest available prices and their timestamps.
  • Click Start / rebalance paper portfolio to simulate trades. Only USD stocks are supported.
  • Static shares stay fixed from the start. Dynamic holdings can be replaced at each rebalance.
  • Stale or closed-market quotes pause paper trades.
  • Download the paper-session JSON before closing. Sessions are not restored after a restart.
Logging in, privacy and troubleshooting
  • Your account lives in a local database managed by Auth.py. Passwords are stored hashed.
  • The dashboard opens through a short-lived sign-in link that expires after 5 minutes. If it expires, press Open dashboard again.
  • "Cannot reach Auth.py": start the site with START_ALL.bat or python Auth.py.
  • Dashboard tab will not load: start it with python -m streamlit run app.py and use localhost:8501.
This tool is for education and research. Results come from historical data, fees are estimates, and no strategy is guaranteed. It is not financial advice, and no brokerage orders are sent.
